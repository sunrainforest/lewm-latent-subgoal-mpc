# 冻结版实验结果

主指标始终为 `proprio_v2` 的 `system_success` / `machine.complete`，不是物理方块到位率。仅 `TRANSFER` 中使用无门控 H=25 成功轨迹检索；其他控制组件不变，Actor 冻结。

| 批次 | seed | Baseline | 无门控 H=25 | 差值 | 配对 95% bootstrap 区间 | 双侧精确 McNemar |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 探索性 | 11100–11199 | 53/100 | 60/100 | +7 点 | −2 到 +16 点 | p=0.2100 |
| 新 seed 复核 | 11200–11299 | 51/100 | 59/100 | +8 点 | −3 到 +19 点 | p=0.2005 |

配对明细：探索批次双方成功 45、仅 Baseline 成功 8、仅检索成功 15、双方失败 32；新 seed 批次依次为 40、11、19、30。新 seed 批次的[预先固定方案](../../experiments/heldout_v0_5_protocol.md)要求正向差值且 `p<0.05` 才可作确认性提升声明，此条件**未达成**。两批同向是值得继续研究的信号，但不应写成已证明稳定提升。

两组方法分别从相同 seed 开始完整回合，不是从完全相同的 `TRANSFER` 快照分叉。GPU、渲染器和模型数值波动可能使轨迹偏离。结果文件 [`summary.json`](summary.json)仅保留可公开汇总统计，不含服务器绝对路径、原始视频、逐步日志或模型权重。用 [`summarize_frozen_ungated_v1.py`](../../experiments/summarize_frozen_ungated_v1.py)可从原始 summary JSON 重新计算这些数值。

历史 50 回合对照（门控与学习型 MLP）保留在 [`../v0.1/`](../v0.1/)；其结论不覆盖此处的两批独立种子结果。
